<objective>
Implement the administrative fund distribution ledger and domain service, enabling non-profit staff to record verified fund expenditures with bill uploads and impact photos while atomically synchronizing campaign distributed balances in a database transaction.

Purpose: Establishes the authoritative financial expense ledger ensuring every disbursement is documented with legal proof and tied directly to cause balances.
Output: StoreFundDistributionRequest, FundDistributionService, AdminFundDistributionController, distribution views, and automated tests.
</objective>

  <name>Task 1: Form Request & Transactional Fund Distribution Domain Service</name>
  <files>app/Http/Requests/StoreFundDistributionRequest.php, app/Services/FundDistributionService.php</files>
  <read_first>app/Models/FundDistribution.php, app/Models/Campaign.php, app/Services/DonationVerificationService.php</read_first>
  <action>
    1. Create `app/Http/Requests/StoreFundDistributionRequest.php`:
       - `title`: required, string, max:255
       - `beneficiary_name`: required, string, max:200
       - `amount_spent`: required, numeric, min:1, max:99999999.99
       - `distribution_date`: required, date, before_or_equal:today
       - `campaign_id`: nullable, exists:campaigns,id
       - `payment_reference`: nullable, string, max:150
       - `proof_bill_image`: nullable, file, mimes:jpeg,png,webp,pdf, max:2048
       - `impact_photos`: nullable, array, max:6
       - `impact_photos.*`: file, mimes:jpeg,png,webp, max:2048
       - `description`: required, string, max:3000
       - `is_public`: nullable, boolean (default true)
    2. Create `app/Services/FundDistributionService.php`:
       - Method `recordDistribution(array $data, ?UploadedFile $billFile = null, array $impactFiles = [], ?int $userId = null): FundDistribution`:
         - Executes within `DB::transaction()`.
         - Stores `$billFile` in `storage/app/public/distributions/bills` if present.
         - Stores `$impactFiles` in `storage/app/public/distributions/impact` and builds JSON array of relative paths.
         - If `$data['campaign_id']` is present:
           - Fetches campaign with `Campaign::lockForUpdate()->findOrFail($data['campaign_id'])`.
           - Increments `$campaign->distributed_amount` by `$data['amount_spent']`.
           - Saves campaign.
         - Creates `FundDistribution` record with `created_by = $userId ?? auth()->id() ?? User::first()->id`.
         - Returns created `FundDistribution`.
  </action>
  <verify>
    Run `php artisan tinker --execute="echo class_exists(\App\Services\FundDistributionService::class);"` - outputs true.
  </verify>
  <acceptance_criteria>
    - Service executes in `DB::transaction()`
    - Campaign `distributed_amount` increments atomically
    - Uploaded files stored securely in public disk
  </acceptance_criteria>
  <done>Domain service and validation request are created.</done>
</task>
