<task type="auto">
  <name>Task 1: Public Transparency Controller & Routes</name>
  <files>app/Http/Controllers/TransparencyController.php, routes/web.php</files>
  <read_first>app/Models/FundDistribution.php, app/Models/Donation.php, app/Models/Campaign.php, routes/web.php</read_first>
  <action>
    1. Create `app/Http/Controllers/TransparencyController.php`:
       - `index(Request $request)`:
         - Calculates high-level verified financial metrics:
           - `$totalRaised = (float) Donation::where('status', 'verified')->sum('amount');`
           - `$totalDistributed = (float) FundDistribution::where('is_public', true)->sum('amount_spent');`
           - `$netReserve = max(0, $totalRaised - $totalDistributed);`
           - `$totalBeneficiaries = FundDistribution::where('is_public', true)->count();`
           - `$utilizationRate = $totalRaised > 0 ? min(100, round(($totalDistributed / $totalRaised) * 100, 1)) : 0;`
         - Calculates category expenditure breakdown (grouping distributions by linked campaign category or campaign title).
         - Queries public distributions:
           - Base query: `FundDistribution::public()->with('campaign')`.
           - Filter by campaign: if `$request->filled('campaign')`, filter by `campaign_id`.
           - Search: if `$request->filled('search')`, search `title`, `beneficiary_name`, `description`.
           - Paginate 12 per page (`withQueryString()`).
         - Fetches all active campaigns for filter dropdown: `Campaign::orderBy('title')->get(['id', 'title', 'slug'])`.
         - Returns `view('transparency.index', [...])`.
       - `campaignLedger(Campaign $campaign)`:
         - Retrieves campaign with its category and its public distributions ordered by `distribution_date` descending.
         - Computes campaign-specific financial balance: Goal, Verified Raised, Total Distributed, Remaining Balance, Utilization %.
         - Returns `view('transparency.campaign', compact('campaign'))`.
    2. Register routes in `routes/web.php`:
       - `GET /transparency` -> `[TransparencyController::class, 'index']->name('transparency.index')`
       - `GET /campaigns/{campaign:slug}/transparency` -> `[TransparencyController::class, 'campaignLedger']->name('campaigns.transparency')`
  </action>
  <verify>
    Run `php artisan route:list --name=transparency` to verify registered endpoints.
  </verify>
  <acceptance_criteria>
    - Routes `transparency.index` and `campaigns.transparency` exist
    - Controller filters only verified donations and public distributions
  </acceptance_criteria>
  <done>TransparencyController and public routes are created.</done>
</task>
