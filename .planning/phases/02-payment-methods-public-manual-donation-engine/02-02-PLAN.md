<objective>
Implement the public donation verification status portal where donors can look up their manual donation status by UTR or phone number, view payment details, read admin verification notes, and access their receipt.

Purpose: Provides complete transparency to donors after making an offline UPI/bank payment, reassuring them that their contribution is safely tracked through manual verification.
Output: DonationStatusController, `/donation-status` Blade view, updated base navigation, and automated feature tests.
</objective>

       - `index(Request $request)`:
         - Accepts optional `query` parameter (from GET parameter or form submission).
         - Sanitizes query by trimming whitespace and common delimiters.
         - If query is provided:
           - Queries `Donation::with('campaign')` where `utr_number = $query` OR `donor_phone = $query` OR `receipt_number = $query`.

         - Returns view `donate.status` with `$donations`, `$query`, and helpful sidebar data (impact categories, contact info from `site_settings`).

       - `GET /donation-status` -> `[DonationStatusController::class, 'index']->name('donation.status')`
  </action>
