Implement the public manual donation submission engine, including active payment method display (UPI QR & bank details), preset amounts, proof screenshot upload, UTR deduplication, and rate-limiting.

Purpose: Enables non-profit organizations to receive manual UPI and bank transfer donations without gateway fees while preventing spam, duplicate submissions, and invalid proof files.
Output: PaymentMethodSeeder, DonationController, StoreDonationRequest, `/donate` Blade view, and automated feature tests.

<task type="auto">
  <name>Task 2: Build StoreDonationRequest with UTR Deduplication and DonationController</name>
  <files>app/Http/Requests/StoreDonationRequest.php, app/Http/Controllers/DonationController.php, routes/web.php</files>
  <read_first>app/Models/Donation.php, routes/web.php</read_first>
  <action>
    1. Create `app/Http/Requests/StoreDonationRequest.php`:
       - `donor_name`: ['required', 'string', 'max:255']
       - `donor_email`: ['required', 'email', 'max:255']
       - `donor_phone`: ['required', 'string', 'regex:/^[0-9+ -]{10,20}$/']
       - `donor_pan`: ['nullable', 'string', 'regex:/^[A-Z]{5}[0-9]{4}[A-Z]{1}$/i']
       - `donor_address`: ['nullable', 'string', 'max:500']
       - `amount`: ['required', 'numeric', 'min:1', 'max:10000000']
       - `payment_mode`: ['required', 'in:upi_qr,bank_transfer']
       - `utr_number`: ['required', 'string', 'min:6', 'max:30', 'unique:donations,utr_number']
       - `payment_screenshot`: ['required', 'file', 'image', 'mimes:jpeg,png,webp', 'max:2048']
       - `campaign_id`: ['nullable', 'exists:campaigns,id']
       - `donor_message`: ['nullable', 'string', 'max:1000']
       - `is_anonymous`: ['nullable', 'boolean']
       - Prepare inputs before validation (e.g. uppercase PAN, trim UTR and phone).
    2. Create `app/Http/Controllers/DonationController.php`:
       - `index(Request $request)`:
         - Fetches active payment methods (`PaymentMethod::active()->get()`).
         - Fetches active campaigns for optional dropdown selection.
         - Fetches recent verified donations (or latest donations) for the recent donor ticker.
         - Returns view `donate.index`.
       - `store(StoreDonationRequest $request)`:
         - Handles file upload: stores `payment_screenshot` to `donations` directory in `public` disk.
         - Creates `Donation` record with `status => 'pending'`.
         - Redirects back with flash success message and UTR tracking link.
    3. Update `routes/web.php`:
       - `GET /donate` -> `[DonationController::class, 'index']->name('donate.index')`
       - `POST /donate` -> `[DonationController::class, 'store']->middleware('throttle:5,1')->name('donate.store')`
  </action>
  <verify>
    Run `php artisan route:list --name=donate` to confirm routes and middleware are registered.
  </verify>
  <acceptance_criteria>
    - `POST /donate` has `throttle:5,1` middleware attached
    - Form request rejects duplicate UTR numbers
    - Form request restricts screenshot files to max 2048KB and jpeg/png/webp types
  </acceptance_criteria>
  <done>Donation submission controller and validation rules enforce security and deduplication.</done>
</task>
