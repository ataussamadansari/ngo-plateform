  <action>
    1. Create `app/Http/Controllers/PageController.php`:
       - `about()`: Returns `view('pages.about')`.
    2. Create `app/Http/Controllers/ContactController.php`:
       - `index()`: Returns `view('pages.contact')`.
       - `store(StoreContactInquiryRequest $request)`:
         - Creates `ContactInquiry` with status 'pending'.
         - Redirects back with flash success message ("Thank you for reaching out. Our team will review your message promptly.").
    3. Create `app/Http/Controllers/Admin/AdminInquiryController.php`:
       - `index(Request $request)`: Lists inquiries with status filter (`all`, `pending`, `read`, `replied`), search filter, paginated.
       - `updateStatus(Request $request, ContactInquiry $inquiry)`: Validates status in `pending,read,replied`, updates record, redirects back.
       - `destroy(ContactInquiry $inquiry)`: Deletes inquiry, redirects back.
    4. Register routes in `routes/web.php`:
       - Public:
         - `GET /about` -> `PageController@about` -> `about`
         - `GET /contact` -> `ContactController@index` -> `contact.index`
         - `POST /contact` -> `ContactController@store` -> `contact.store` (throttle:5,1)
       - Admin:
         - `GET /admin/inquiries` -> `AdminInquiryController@index` -> `admin.inquiries.index`
         - `PATCH /admin/inquiries/{inquiry}` -> `AdminInquiryController@updateStatus` -> `admin.inquiries.update`
         - `DELETE /admin/inquiries/{inquiry}` -> `AdminInquiryController@destroy` -> `admin.inquiries.destroy`
  </action>
  <verify>
    Run `php artisan route:list --name=contact` to verify public and admin endpoints.
  </verify>

    - Admin inquiry management routes registered under `admin.` prefix
