# Plan 13-01: Global Shell Polish (Header, Navigation, Mobile Drawer & Footer)

## Context & Objective

The public website layout (`resources/views/layouts/base.blade.php`) currently has a basic navbar and footer. The reference design (`docs/ui/Hope Foundation_ Together for Tomorrow.png`) specifies:
1. **Clean Brand Header**:
   - Leaf/Heart icon badge + NGO Name ("Hope Foundation" or `setting('ngo_name')`) + Tagline ("For a Better Tomorrow" or `setting('ngo_tagline')`).
   - Clean horizontal desktop navigation links: Home, About Us, Campaigns, Transparency, Events, Volunteer, Contact.
   - Quick Search icon button.
   - Solid Emerald `Donate Now` action pill button.
2. **Alpine.js Mobile Slide-out Drawer**:
   - Modern off-canvas drawer with smooth transition and backdrop overlay.
   - Navigation links with active route indicator.
   - Quick contact details and social media icons in the drawer.
3. **4-Column High-Trust Footer**:
   - Column 1: Organization brand + mission description + social handles (Facebook, Instagram, YouTube, X).
   - Column 2: Quick Links (Home, About Us, Campaigns, Transparency, Events, Volunteer, Contact).
   - Column 3: Our Work / Cause Categories (Education, Healthcare, Clean Water, Environment, Community Support).
   - Column 4: Contact Coordinates (Address, Phone, Email) + inline `Donate Now` button.
   - Sub-footer: Copyright `© 2026 Hope Foundation` + legal links (Privacy Policy, Terms & Conditions, Disclaimer).
   - Preserve legal accreditation numbers (80G, 12A, PAN, Darpan) cleanly in the footer or compliance strip.

---

## Proposed Changes

### 1. `resources/views/layouts/base.blade.php`

- Update HTML structure:
  - Add Google Fonts for clean typography (e.g., `Inter` and a script/serif font for accents if needed, or sleek system sans).
  - Setup Alpine.js state `x-data="{ mobileMenuOpen: false, searchOpen: false }"` on the header/body.
  - Implement the sticky navbar with precise height (`h-20`), shadow, and border matching the mockup.
  - Implement off-canvas slide-over drawer with `x-show="mobileMenuOpen"` with transition directives (`x-transition:enter`, `x-transition:leave`).
  - Redesign the footer into the exact 4-column structure with dark green/slate backdrop (`bg-[#091e17]` or `bg-slate-950`).
  - Maintain the admin command bar for authenticated administrators (`@auth`).

### 2. Assets & Styling

- Check `resources/css/app.css` to ensure smooth utility classes, custom colors, and font definitions work seamlessly with Tailwind v4.
