<task type="auto">
  <name>Task 1: Public Campaign Controller & Routing</name>
  <files>app/Http/Controllers/CampaignController.php, routes/web.php</files>
  <read_first>app/Models/Campaign.php, app/Models/CauseCategory.php, routes/web.php</read_first>
  <action>
    1. Create `app/Http/Controllers/CampaignController.php`:
       - `index(Request $request)`:
         - Base query: `Campaign::active()->with('category')`.
         - Filter by category: if `$request->filled('category')`, filter where `category_id = $id` or join category slug.
         - Filter by status/tab: default `active`, can filter `completed`.
         - Search: if `$request->filled('search')`, search `title` and `short_description`.
         - Urgent campaigns: `Campaign::active()->urgent()->take(3)->get()`.
         - Paginates 9 per page (`withQueryString()`).
         - Categories list: `CauseCategory::active()->withCount(['campaigns' => fn($q) => $q->active()])->get()`.
         - Returns `view('campaigns.index', ...)`.
       - `show(Campaign $campaign)`:
         - If `$campaign->status === 'draft'`, abort 404.
         - Eager loads `category`, `verifiedDonations` (ordered by `created_at` desc, limit 10), and `fundDistributions` (public, limit 5).
         - Computes metrics: `progressPercentage`, `remainingAmount`, verified donors count (`$campaign->verifiedDonations()->count()`).
         - Returns `view('campaigns.show', compact('campaign', ...))`.
    2. Register public routes in `routes/web.php`:
       - `GET /campaigns` -> `[CampaignController::class, 'index']->name('campaigns.index')`
       - `GET /campaigns/{campaign:slug}` -> `[CampaignController::class, 'show']->name('campaigns.show')`
  </action>
  <verify>
    Run `php artisan route:list --name=campaigns` to verify registered endpoints.
  </verify>
  <acceptance_criteria>
    - Public routes `campaigns.index` and `campaigns.show` are registered
    - Controller restricts public view to active/published campaigns
  </acceptance_criteria>
  <done>CampaignController and public routes are created.</done>
