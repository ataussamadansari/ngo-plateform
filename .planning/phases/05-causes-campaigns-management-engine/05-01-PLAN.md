<task type="auto">
  <name>Task 2: Admin Campaign Controller & Routes</name>
  <files>app/Http/Controllers/Admin/AdminCampaignController.php, routes/web.php</files>
  <read_first>app/Models/Campaign.php, routes/web.php</read_first>
  <action>
    1. Create `app/Http/Controllers/Admin/AdminCampaignController.php`:
       - `index(Request $request)`:
         - Queries `Campaign::with('category')->withCount('verifiedDonations')`.
         - Filters by `status` (all, draft, active, completed, paused), `category_id`, search keyword (`title`, `short_description`).
         - Paginates 12 per page.
         - Metrics: Total Campaigns, Active Campaigns, Total Goal, Total Raised across campaigns.
         - Returns `view('admin.campaigns.index', ...)`.
       - `create()`:
         - Loads active categories: `CauseCategory::active()->orderBy('name')->get()`.
         - Returns `view('admin.campaigns.create', compact('categories'))`.
       - `store(StoreCampaignRequest $request)`:
         - Handles `thumbnail_image` upload to `storage/app/public/campaigns/thumbnails`.
         - Handles `gallery_images` uploads to `storage/app/public/campaigns/galleries`.
         - Generates unique slug using `Str::slug($request->title)` if slug not provided.
         - Creates `Campaign` record.
         - Redirects to `admin.campaigns.index` with success flash message.
       - `edit(Campaign $campaign)`:
         - Loads categories and returns `view('admin.campaigns.edit', compact('campaign', 'categories'))`.
       - `update(UpdateCampaignRequest $request, Campaign $campaign)`:
         - Updates fields; replaces thumbnail if new file uploaded; appends or updates gallery images if provided.
         - Saves and redirects to `admin.campaigns.index` with success flash message.
       - `toggleStatus(Request $request, Campaign $campaign)`:
         - Validates `status` in draft, active, completed, paused.
         - Updates status and returns redirect with success message.
    2. Register administrative routes in `routes/web.php` under `admin.` prefix:
       - Category routes:
         - `GET /admin/categories` -> `AdminCategoryController@index` -> `admin.categories.index`
         - `POST /admin/categories` -> `AdminCategoryController@store` -> `admin.categories.store`
         - `PUT /admin/categories/{category}` -> `AdminCategoryController@update` -> `admin.categories.update`
         - `DELETE /admin/categories/{category}` -> `AdminCategoryController@destroy` -> `admin.categories.destroy`
       - Campaign routes:
         - `GET /admin/campaigns` -> `AdminCampaignController@index` -> `admin.campaigns.index`
         - `GET /admin/campaigns/create` -> `AdminCampaignController@create` -> `admin.campaigns.create`
         - `POST /admin/campaigns` -> `AdminCampaignController@store` -> `admin.campaigns.store`
         - `GET /admin/campaigns/{campaign}/edit` -> `AdminCampaignController@edit` -> `admin.campaigns.edit`
         - `PUT /admin/campaigns/{campaign}` -> `AdminCampaignController@update` -> `admin.campaigns.update`
         - `PATCH /admin/campaigns/{campaign}/status` -> `AdminCampaignController@toggleStatus` -> `admin.campaigns.status`
  </action>
  <verify>
    Run `php artisan route:list --name=admin.campaigns` to verify registered endpoints.
  </verify>
  <acceptance_criteria>
    - Admin routes for categories and campaigns registered cleanly
    - Campaign CRUD actions handle file uploads and slug generation
  </acceptance_criteria>
  <done>Admin campaign controller and routes are functional.</done>
</task>
