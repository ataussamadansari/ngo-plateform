       - Record title attribute: `'receipt_number'`.

       - Create `resources/views/filament/resources/donations/proof-modal.blade.php` displaying donor name, amount, UTR number in copyable font, and payment screenshot image.

       - Manual donation recording fields for `CreateDonation`:
         - Donor name (required), email, phone (required), PAN number (uppercase, regex validation), address.
         - Amount (numeric, min 1, prefix '₹', required), payment mode (`cash`, `upi_qr`, `bank_transfer`, default `cash`).
         - Campaign select (`campaign_id`, nullable).
         - UTR number (optional for cash, unique).
         - Admin remarks, is_anonymous toggle.
       - Custom creation logic in `CreateDonation` invoking `DonationVerificationService::createDirectVerified()`.
    5. Configure `DonationsTable`:
       - Columns:
         - `receipt_number`: TextColumn, copyable, search, placeholder '-'
         - `donor_name`: TextColumn, searchable, sortable, weight 'bold'
         - `amount`: TextColumn, money 'INR', sortable
         - `payment_mode`: TextColumn, badge
         - `campaign.title`: TextColumn, badge, placeholder 'General Fund'
         - `status`: TextColumn, badge with colors (pending: warning, verified: success, rejected: danger)
         - `utr_number`: TextColumn, copyable, searchable
         - `created_at`: TextColumn, dateTime, sortable
       - Filters:
         - SelectFilter on `status` (pending, verified, rejected)
         - SelectFilter on `campaign_id`
         - SelectFilter on `payment_mode`
       - Row Actions:
         - `proof_check`: Modal displaying side-by-side proof view.
         - `approve`: Calls `DonationVerificationService::approve($record, auth()->id())`, sends success notification. Visible when `status === 'pending'`.
         - `reject`: Modal requiring `admin_remarks`, calls `DonationVerificationService::reject($record, $data['admin_remarks'], auth()->id())`. Visible when `status === 'pending'`.
         - `download_receipt`: Streams/downloads 80G PDF receipt via `ReceiptPdfService::generate($record)`. Visible when `status === 'verified'`.
