<task type="auto">
  <name>Task 1: Build Global Cached `setting()` Helper and SiteSetting Cache Buster</name>
  <files>app/helpers.php, composer.json, app/Models/SiteSetting.php</files>
  <read_first>composer.json, app/Models/SiteSetting.php</read_first>
  <action>
    1. Create `app/helpers.php` defining:
       ```php
       if (! function_exists('setting')) {
           function setting(string $key, mixed $default = null): mixed
           {
               $settings = \Illuminate\Support\Facades\Cache::rememberForever('site_settings', function () {
                   return \App\Models\SiteSetting::all()->pluck('value', 'key')->toArray();
               });

               return $settings[$key] ?? $default;
           }
       }
       ```
    2. Register `app/helpers.php` in `composer.json` under `autoload.files`:
       ```json
       "autoload": {
           "files": [
               "app/helpers.php"
           ],
           "psr-4": { ... }
       }
       ```
       Run `composer dump-autoload`.
    3. Update `app/Models/SiteSetting.php` to include model lifecycle hooks:
       ```php
       protected static function booted(): void
       {
           static::saved(fn () => \Illuminate\Support\Facades\Cache::forget('site_settings'));
           static::deleted(fn () => \Illuminate\Support\Facades\Cache::forget('site_settings'));
       }
       ```
  </action>
  <verify>
    Run `composer dump-autoload` followed by:
    `php artisan tinker --execute="\App\Models\SiteSetting::updateOrCreate(['key' => 'test_key'], ['value' => 'test_val']); echo setting('test_key'); \App\Models\SiteSetting::where('key', 'test_key')->delete();"`
    Confirm it prints `test_val` without errors.
  </verify>
  <acceptance_criteria>
    - `setting('key', 'fallback')` resolves without fatal errors in CLI and HTTP
    - Changing a setting invalidates the `site_settings` cache immediately
  </acceptance_criteria>
  <done>Cached settings engine is operational with automatic cache invalidation.</done>
