<task type="auto">
  <name>Task 1: Build DonationVerificationService with Atomic DB::transaction() Logic</name>
  <files>app/Services/DonationVerificationService.php</files>
  <read_first>app/Models/Donation.php, app/Models/Campaign.php</read_first>
  <action>
    Create `app/Services/DonationVerificationService.php` providing:
    1. `approve(Donation $donation, ?int $verifiedById = null): Donation`:
       - Executes within `DB::transaction()`:
         - Locks `$donation = Donation::lockForUpdate()->findOrFail($donation->id)`
         - Verifies `$donation->status === 'pending'`.
         - Generates sequential receipt number:
           - Prefix = `setting('receipt_prefix', 'KSF')`
           - Year = date('Y')
           - Count = `Donation::whereNotNull('receipt_number')->where('receipt_number', 'LIKE', "{$prefix}-{$year}-%")->count() + 1`
           - Sequential format: `sprintf("%s-%s-%04d", $prefix, $year, $count)`
         - Updates `$donation`:
           - `status => 'verified'`
           - `receipt_number => $receiptNumber`
           - `verified_by => $verifiedById`
           - `verified_at => now()`
           - `$donation->save()`
         - If `$donation->campaign_id`:
           - Atomically increments linked campaign: `Campaign::where('id', $donation->campaign_id)->increment('raised_amount', $donation->amount)`.
         - Returns verified `$donation`.
    2. `reject(Donation $donation, string $remarks, ?int $verifiedById = null): Donation`:
       - Updates `$donation`:
         - `status => 'rejected'`
         - `admin_remarks => $remarks`
         - `verified_by => $verifiedById`
         - `verified_at => now()`
         - `$donation->save()`
       - Returns rejected `$donation`.
    3. `createDirectVerified(array $data, ?int $createdById = null): Donation`:
       - Executes within `DB::transaction()`:
         - Generates sequential receipt number.
         - Creates `Donation` with `status => 'verified'`, `receipt_number`, `verified_by => $createdById`, `verified_at => now()`.
         - If `campaign_id` provided, increments linked campaign `raised_amount`.
         - Returns created `$donation`.
  </action>
  <verify>
    Verify in tinker that approving a donation updates campaign balance and generates formatted receipt number.
  </verify>
  <acceptance_criteria>
    - `approve()` is atomic and increments campaign `raised_amount`
    - Receipt numbers increment sequentially without collisions
    - `reject()` preserves admin remarks
  </acceptance_criteria>
  <done>Verification service guarantees atomic financial state transitions.</done>
