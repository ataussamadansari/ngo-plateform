Purpose: Empowers NGOs to issue legally compliant 80G tax exemption receipts without manual paperwork or third-party paid services.
Output: ReceiptPdfService, ReceiptController, 80G receipt Blade template, public and admin download links, and automated tests.
</objective>

<task type="auto">
  <name>Task 2: Design 80G Compliant Receipt Blade Template & ReceiptController</name>
  <files>resources/views/receipts/80g.blade.php, app/Http/Controllers/ReceiptController.php, routes/web.php</files>
  <read_first>app/Models/Donation.php, routes/web.php</read_first>
  <action>
    1. Create `resources/views/receipts/80g.blade.php`:
       - High-fidelity, print-perfect CSS designed for Dompdf rendering.
       - Header: Organization Logo (or initials badge), NGO Name, Registered Address, Registration No., NGO PAN.
       - 80G Exemption Box: Prominent border box: "Donations are exempt from Income Tax under Section 80G of the Income Tax Act, 1961. Reg. No: {{ setting('80g_reg_number') }}".
       - Receipt Details:
         - Receipt Number (e.g. `KSF-2026-0001`)
         - Date of Issue & Financial Year
       - Donor Details:
         - Full Name
         - PAN Number (or 'Not Provided' if not supplied)
         - Phone Number & Email
         - Address
       - Transaction Details Table:
         - Amount (Figures): ₹{{ number_format($donation->amount, 2) }}
         - Amount (Words): {{ $amountInWords }}
         - Payment Mode: UPI / Bank Transfer / Cash
         - Transaction / UTR Ref No: {{ $donation->utr_number }}
         - Date of Credit: {{ $donation->verified_at?->format('d/m/Y') }}
         - Purpose / Campaign: {{ $donation->campaign->title ?? 'General Relief Fund' }}
       - Footer:
         - Authorized signatory digital signature image from `storage/app/public/` . `setting('authorized_sign_image')`.
         - Signatory name: `{{ setting('authorized_sign_name', 'Authorized Signatory') }}`.
         - Official seal stamp graphic and disclaimer: "This is a computer-generated receipt issued by a registered non-profit organization."
    2. Create `app/Http/Controllers/ReceiptController.php`:
       - `download(Donation $donation, ReceiptPdfService $pdfService)`:
         - Abort 404 if `$donation->status !== 'verified'`.
         - Generates PDF using `$pdfService->generatePdf($donation)`.
         - Returns `$pdf->download("Receipt-{$donation->receipt_number}.pdf")`.
       - `preview(Donation $donation, ReceiptPdfService $pdfService)`:
         - Returns `$pdf->stream("Receipt-{$donation->receipt_number}.pdf")` for inline browser inspection.
    3. Update `routes/web.php`:
       - `GET /donations/{donation}/receipt` -> `[ReceiptController::class, 'download']->name('donation.receipt')`
       - `GET /donations/{donation}/receipt/preview` -> `[ReceiptController::class, 'preview']->name('donation.receipt.preview')`
  </action>
  <verify>
    Run `php artisan route:list --name=donation.receipt` to confirm routes.
  </verify>
  <acceptance_criteria>
    - Route `donation.receipt` generates PDF with content-type `application/pdf`
    - Non-verified donations return 404 on receipt download attempt
  </acceptance_criteria>
  <done>Official 80G receipt template and download endpoints are operational.</done>
</task>
