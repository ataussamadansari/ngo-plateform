    Create `app/Http/Controllers/Admin/AdminDashboardController.php`:
    - Define method `index(Request $request): View`:
      - Compute financial metrics using Eloquent aggregations:
        - `$totalVerifiedFunds = (float) Donation::where('status', 'verified')->sum('amount');`
        - `$totalDistributedFunds = (float) FundDistribution::sum('amount_spent');`
        - `$availableBalance = max(0.00, $totalVerifiedFunds - $totalDistributedFunds);`
        - `$pendingDonationsCount = (int) Donation::where('status', 'pending')->count();`
        - `$pendingVolunteersCount = (int) Volunteer::where('status', 'pending')->count();`
        - `$pendingInquiriesCount = (int) ContactInquiry::where('status', 'pending')->count();`
        - `$activeCampaignsCount = (int) Campaign::where('status', 'active')->count();`
        - `$totalDonorsCount = (int) Donation::where('status', 'verified')->distinct('phone')->count();`
      - Query actionable items for quick triage widgets:
        - `$pendingDonations = Donation::where('status', 'pending')->with('campaign', 'paymentMethod')->latest()->take(5)->get();`
        - `$pendingVolunteers = Volunteer::where('status', 'pending')->latest()->take(5)->get();`
        - `$activeCampaigns = Campaign::where('status', 'active')->with('category')->latest()->take(4)->get();`
        - `$recentDistributions = FundDistribution::with('campaign')->latest('distribution_date')->take(5)->get();`
      - Return `view('admin.dashboard', compact(...))`.
    - Register routes in `routes/web.php` inside the `admin.` group:
      - `Route::get('/', [AdminDashboardController::class, 'index'])->name('dashboard');`
      - `Route::get('/dashboard', [AdminDashboardController::class, 'index'])->name('dashboard.alias');`
  </action>
