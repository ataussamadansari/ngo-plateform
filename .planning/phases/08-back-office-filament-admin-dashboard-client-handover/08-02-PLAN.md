  <name>Task 1: Admin Authentication Gateway (Login & Logout)</name>
  <files>app/Http/Controllers/Admin/AdminAuthController.php, resources/views/admin/auth/login.blade.php, routes/web.php</files>
  <read_first>app/Models/User.php, routes/web.php, resources/views/layouts/base.blade.php</read_first>
  <action>
    Create `app/Http/Controllers/Admin/AdminAuthController.php`:
    - Method `showLoginForm(): View`: Returns `resources/views/admin/auth/login.blade.php`. If already logged in as admin/manager, redirect to `route('admin.dashboard')`.
    - Method `login(Request $request): RedirectResponse`:
      - Validate `email` (required|email) and `password` (required|string).
      - Attempt `Auth::attempt($credentials, $request->boolean('remember'))`.
      - If authentication succeeds:
        - Verify `$user->is_active`. If inactive, `Auth::logout()` and redirect back with error 'Account is disabled. Contact super admin.'
        - Verify `$user->isSuperAdmin() || $user->isManager()`. If neither, `Auth::logout()` and redirect back with error 'Access denied. Administrative role required.'
        - Regenerate session: `$request->session()->regenerate()`.
        - Redirect intended to `route('admin.dashboard')` with success message.
      - If authentication fails, redirect back with error 'The provided credentials do not match our records.'
    - Method `logout(Request $request): RedirectResponse`:
      - Call `Auth::logout()`.
      - Invalidate session: `$request->session()->invalidate()`.
      - Regenerate CSRF token: `$request->session()->regenerateToken()`.
      - Redirect to `route('admin.login')` with notice 'You have been logged out successfully.'
    
    Create `resources/views/admin/auth/login.blade.php`:
      - Centered, high-trust administrative sign-in portal.
      - Branded with dynamic NGO logo (`setting('ngo_logo')`), NGO name (`setting('ngo_name')`), and primary color styling.
      - Email and password fields with validation error feedback.
      - "Remember Me" checkbox.
      - Submit button: "Sign In to Back-Office".
      - Return link: "Back to Public Website".

    Register routes in `routes/web.php`:
      - `Route::get('/admin/login', [AdminAuthController::class, 'showLoginForm'])->name('admin.login');`
      - `Route::post('/admin/login', [AdminAuthController::class, 'login'])->middleware('throttle:5,1')->name('admin.login.submit');`
      - `Route::post('/admin/logout', [AdminAuthController::class, 'logout'])->name('admin.logout');`
  </action>
  <verify>
    <command>php artisan route:list --name=admin.login</command>
    <expected>Routes `admin.login` and `admin.login.submit` registered.</expected>
  </verify>
</task>

    Create `app/Http/Middleware/EnsureAdminRole.php`:

      - Check `Auth::check()`. If false, redirect to `route('admin.login')`.
      - Check `$user = Auth::user()`.
      - Check `$user->is_active`. If false, logout and redirect with error.
      - Check if user role is in allowed roles (`super_admin`, `manager` by default, or specific role if passed as parameter `$role = null`).

      - In `withMiddleware()`, register `$middleware->alias(['admin.role' => \App\Http\Middleware\EnsureAdminRole::class]);`.

    Wrap all `/admin/*` protected routes in `routes/web.php`:
      - Apply `middleware(['auth', 'admin.role'])` to the `admin.` group (excluding the public login routes).
      - Ensure all existing feature tests can authenticate as super admin or manager.

    Update navigation header in base layout:
      - When an admin is authenticated (`auth()->check() && (auth()->user()->isSuperAdmin() || auth()->user()->isManager())`), display an admin command strip or link to `Back-Office Dashboard` and logout action.
