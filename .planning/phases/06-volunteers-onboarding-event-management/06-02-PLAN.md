<task type="auto">
  <name>Task 1: Event Form Requests & Controllers</name>
  <files>app/Http/Requests/StoreEventRequest.php, app/Http/Requests/UpdateEventRequest.php, app/Http/Requests/RegisterEventRequest.php, app/Http/Controllers/EventController.php, app/Http/Controllers/Admin/AdminEventController.php, routes/web.php</files>
  <read_first>app/Models/Event.php, app/Models/EventRegistration.php, routes/web.php</read_first>
  <action>
    1. Create `StoreEventRequest` and `UpdateEventRequest`:
       - `title`: required, string, max:255
       - `slug`: nullable, string, max:255, unique:events,slug
       - `description`: required, string
       - `banner_image`: file, image, mimes:jpeg,png,webp, max:2048 (required in store, nullable in update)
       - `location_name`: required, string, max:255
       - `address`: required, string
       - `google_map_link`: nullable, url, max:500
       - `event_date`: required, date
       - `start_time`: required, string
       - `end_time`: nullable, string
       - `max_participants`: nullable, integer, min:1
       - `status`: required, in:upcoming,ongoing,completed,cancelled
    2. Create `RegisterEventRequest`:
       - `participant_name`: required, string, max:150
       - `participant_phone`: required, string, max:20
       - `participant_email`: nullable, email, max:150
    3. Create `app/Http/Controllers/EventController.php`:
       - `index(Request $request)`:
         - Tab filter: `upcoming` (default, `Event::upcoming()`) vs `past` (`Event::past()`).
         - Eager loads `registrations` count.
         - Search filter by title or location.
         - Returns `view('events.index', ...)`.
       - `show(Event $event)`:
         - Loads registrations count: `$event->loadCount('registrations')`.
         - Calculates `isFull`: `$event->max_participants && $event->registrations_count >= $event->max_participants`.
         - Returns `view('events.show', compact('event', 'isFull'))`.
       - `register(RegisterEventRequest $request, Event $event)`:
         - If event status != 'upcoming' && status != 'ongoing', redirect back with error.
         - If `$event->max_participants && $event->registrations()->count() >= $event->max_participants`, redirect back with error ("Event is at full capacity").
         - If `$event->registrations()->where('participant_phone', $request->participant_phone)->exists()`, redirect back with error ("Already registered for this event").
         - Checks for approved volunteer matching phone or email:
           `$volunteer = Volunteer::where('phone', $request->participant_phone)->orWhere('email', $request->participant_email)->first();`
         - Creates `EventRegistration`: `event_id`, `volunteer_id` (if matched), `participant_name`, `participant_phone`, `participant_email`, `role_assigned` => $volunteer ? 'Volunteer' : 'Participant', `attendance_status` => 'registered'.
         - Redirects back with success message.
    4. Create `app/Http/Controllers/Admin/AdminEventController.php`:
       - `index(Request $request)`: List events with participant counts, search, status filter.
       - `create()`: Returns `view('admin.events.create')`.
       - `store(StoreEventRequest $request)`: Stores banner in `storage/app/public/events/banners`, creates event, redirects with success.
       - `edit(Event $event)`: Returns `view('admin.events.edit', compact('event'))`.
       - `update(UpdateEventRequest $request, Event $event)`: Updates fields, replaces banner if uploaded, redirects with success.
       - `participants(Event $event)`: List event registrations with filter by attendance status (`registered`, `attended`, `absent`) and search.
       - `updateAttendance(Request $request, Event $event, EventRegistration $registration)`: Validates `attendance_status` in `registered,attended,absent`, updates record, redirects back with success.
       - `addParticipant(Request $request, Event $event)`: Admin manual participant addition with name, phone, email, and role.
    5. Register routes in `routes/web.php`:
       - Public:
         - `GET /events` -> `EventController@index` -> `events.index`
         - `GET /events/{event:slug}` -> `EventController@show` -> `events.show`
         - `POST /events/{event:slug}/register` -> `EventController@register` -> `events.register` (throttle:5,1)
       - Admin:
         - `GET /admin/events` -> `AdminEventController@index` -> `admin.events.index`
         - `GET /admin/events/create` -> `AdminEventController@create` -> `admin.events.create`
         - `POST /admin/events` -> `AdminEventController@store` -> `admin.events.store`
         - `GET /admin/events/{event}/edit` -> `AdminEventController@edit` -> `admin.events.edit`
         - `PUT /admin/events/{event}` -> `AdminEventController@update` -> `admin.events.update`
         - `GET /admin/events/{event}/participants` -> `AdminEventController@participants` -> `admin.events.participants`
         - `PATCH /admin/events/{event}/registrations/{registration}/attendance` -> `AdminEventController@updateAttendance` -> `admin.events.attendance`
         - `POST /admin/events/{event}/participants` -> `AdminEventController@addParticipant` -> `admin.events.addParticipant`
  </action>
  <verify>
    Run `php artisan route:list --name=events` to verify registered public and admin endpoints.
  </verify>
  <acceptance_criteria>
    - Public and admin event routes registered cleanly
    - Registration validates capacity and auto-links existing volunteer records
  </acceptance_criteria>
  <done>Event requests, controllers, and routes are configured.</done>
</task>
